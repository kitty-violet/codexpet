# 使用说明

## 安装位置

Codex 自定义宠物目录为：

```text
%USERPROFILE%\.codex\pets
```

在当前 Windows 用户下，这个路径会自动展开到用户主目录下的 `.codex\pets` 文件夹。

## 安装步骤

1. 关闭 Codex 的所有窗口。
2. 打开本仓库目录。
3. 复制以下三个文件夹到 `%USERPROFILE%\.codex\pets`：
   - `dora`
   - `gugu-gaga`
   - `miku`
4. 确认每个文件夹中同时存在 `pet.json` 和 `spritesheet.webp`。
5. 重新启动 Codex。

## 卸载

关闭 Codex 后，删除 `%USERPROFILE%\.codex\pets` 中对应的宠物文件夹即可。卸载不会影响 Codex 本体或其他配置。

## 常见问题

### 重启后没有显示宠物

请检查以下事项：

- Codex 是否已经完全退出；
- 文件夹名称是否保持为 `dora`、`gugu-gaga`、`miku`；
- `pet.json` 中的 `spritesheetPath` 是否仍为 `spritesheet.webp`；
- 精灵图文件是否与 `pet.json` 位于同一目录。

### 图片显示异常

请确认没有单独移动或重命名 `spritesheet.webp`。如果修改了文件名，需要同步修改同目录 `pet.json` 中的 `spritesheetPath`。

### 是否需要复制整个仓库

不需要。运行时只需要将宠物目录复制到 Codex 的 `pets` 目录；仓库中的文档用于说明和维护。
