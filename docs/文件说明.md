## 宠物资源

- `dora`：粉色、喜欢橘子的伙伴。
- `gugu-gaga`：黑色、圆滚滚的企鹅伙伴。
- `miku`：青色双马尾、喜欢大蒜的伙伴。

## 不应提交的文件

以下内容不应放进本仓库：

- `auth.json`；
- API 密钥和访问令牌；
- 本机用户目录下的私密配置；
- 运行日志和临时文件；
- 与宠物资源无关的个人文件。
