# 配置说明

## `pet.json` 示例

```json
{
  "id": "dora",
  "displayName": "dora",
  "description": "一只软乎乎、喜欢橘子的粉色小伙伴。",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp"
}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | 字符串 | 宠物的稳定标识。建议只使用小写字母、数字和连字符。 |
| `displayName` | 字符串 | 在界面中显示的宠物名称。 |
| `description` | 字符串 | 宠物的简短介绍。 |
| `spriteVersionNumber` | 数字 | 精灵图格式版本。当前资源使用 `2`。 |
| `spritesheetPath` | 字符串 | 相对于当前 `pet.json` 的精灵图路径。 |

## 修改配置

修改 `pet.json` 后，请确认：

1. JSON 格式有效；
2. `id` 与目录用途保持一致；
3. `spritesheetPath` 指向实际存在的图片文件；
4. 不要在配置中写入 API 密钥、登录令牌或个人隐私信息。

## 添加新宠物

1. 新建一个独立目录。
2. 放入新的 `pet.json`。
3. 放入对应的 `spritesheet.webp` 或其他受支持的精灵图文件。
4. 在 `pet.json` 中填写唯一的 `id` 和正确的 `spritesheetPath`。
5. 按照 [使用说明](使用说明.md) 将该目录复制到 Codex 的 `pets` 目录。
